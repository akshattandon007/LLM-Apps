# Security Policy

## Supported Versions

This is an active development repo. The latest commit on `main` is the supported version.

## Reporting a Vulnerability

If you discover a security issue, please **do not** open a public issue.

Send details to **akshattandon4@gmail.com** with:
- A brief description of the issue
- Steps to reproduce (if applicable)
- Any suggested fix (optional)

You should receive a response within 5 business days. If the issue is confirmed, a fix will be prioritised and released as soon as possible.

## Scope

This repo contains experimental AI agent projects. Secrets (API keys, tokens) should never be committed — environment variables or `.env` files are the expected pattern. If you find a leaked credential in a commit, report it immediately via email.
