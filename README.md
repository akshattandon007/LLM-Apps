## 🤔 Why LLM-Apps?

- 💡 **Discover practical AI agent apps** — from podcast generators to parking assistants, each project solves a real-world problem using LLMs.
- 🔥 **Multi-model support** — explore apps built with **Claude Opus 4.6**, **Google Gemini**, **Google Gemma**, and more.
- 🛠️ **RAG, Agents & Prompt Engineering** — learn how to combine retrieval-augmented generation, agentic AI, and advanced prompt libraries.
- 🎓 **Learn by building** — well-documented projects you can clone, run, and extend.

## 🚀 Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/akshattandon007/LLM-Apps.git
   ```

2. **Navigate to the desired project directory**

   ```bash
   cd LLM-Apps/Car-Park-agent\ Gemini\ 3.1\ Pro
   ```

3. **Install the required dependencies**

   ```bash
   pip install -r requirements.txt
   ```

4. **Follow the project-specific instructions** in each project's directory to set up API keys and run the app.
