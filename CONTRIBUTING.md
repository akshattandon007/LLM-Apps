# Contributing

Thanks for your interest! This repo is a personal collection, but suggestions and fixes are welcome.

## How to contribute

1. **Check existing issues** — see if someone else already raised your idea.
2. **Open an issue** — describe the bug or feature. For feature requests, explain the problem it solves for everyday people.
3. **Fork and PR** — if you'd like to code it yourself:
   - One project per PR
   - Include a brief README with install/usage
   - Keep it self-contained (the repo is organised by category)
   - Test your changes if applicable

## Project categories

| Directory | What goes there |
|-----------|----------------|
| `ai-agents/` | Single-purpose AI apps for everyday people |
| `advanced-ai-agents/` | Multi-agent orchestration, autonomous workflows |
| `mcp-agents/` | MCP servers connecting to real-world services |
| `extensions/` | Standalone modules, scripts, utilities |
| `rag/` | Retrieval augmented generation projects |
