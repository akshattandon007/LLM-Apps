# Lease Reader

A RAG application that lets you upload a lease/rental agreement PDF and ask
natural-language questions about your rights and obligations.

**Stack:** Python FastAPI + Next.js frontend + FAISS vector store +
sentence-transformers + Claude (via langchain-anthropic)

---

## Architecture

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│   Next.js UI    │────▶│  FastAPI Backend │────▶│  FAISS + ST     │
│  (Chat + Upload)│     │  (main.py)       │     │  (vector store) │
└─────────────────┘     └──────────────────┘     └─────────────────┘
                               │
                               ▼
                        ┌──────────────────┐
                        │  Claude (LLM)    │
                        │  via langchain   │
                        └──────────────────┘
```

### Pipeline

1. **Ingestion:** PDF → PyMuPDF (text extraction) → chunker (section-boundary
   splitting) → domain tagging (RENT, TERMINATION, ACCESS, etc.) →
   sentence-transformers (embeddings) → FAISS index
2. **Query:** User question → classifier (legal domain prediction) → domain-filtered
   FAISS search → top-k chunks → Claude (plain-English answer + clause citation
   + caveat)

## Quick Start

### 1. Backend

```bash
# Create virtual environment (on /tmp as per project policy)
python3 -m venv /tmp/lease-reader-venv
source /tmp/lease-reader-venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Set your Anthropic API key
cp .env.example .env
# Edit .env and add your ANTHROPIC_API_KEY

# Generate the sample lease PDF
python data/generate_sample_lease.py

# Start the server
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000, upload the sample lease, and start asking questions.

### 3. Run Tests

```bash
# From the project root with the venv active
source /tmp/lease-reader-venv/bin/activate
python -m pytest tests/test_smoke.py -v
```

The end-to-end test (which requires ANTHROPIC_API_KEY) is automatically skipped
if the key is not set.

| Method | Path | Description |
|--------|------|-------------|
| GET | `/health` | Health check |
| POST | `/ingest` | Upload a lease PDF (multipart/form-data) |

```bash
curl -X POST http://localhost:8000/ingest \
  -F "file=@data/sample_lease.pdf"
```

### Example: Query

```bash
curl -X POST http://localhost:8000/query \
  -H "Content-Type: application/json" \
  -d '{"question": "Can my landlord enter without notice?", "top_k": 5}'
```

## Legal Domains

The classifier and chunker tag content into these domains:

- **RENT** — Rent amounts, late fees, payment terms, increases
- **TERMINATION** — Early termination, notice periods, abandonment
- **ACCESS** — Landlord entry, inspection, showings
- **MAINTENANCE** — Repairs, habitability, emergencies
- **PETS** — Pet policies, fees, service animals
- **SUBLETTING** — Sublease, assignment, roommates
- **DEPOSIT** — Security deposit, refunds, deductions
- **UTILITIES** — Utility responsibility, billing
- **GENERAL** — Fallback for unclassified content

---

## Caveat Engine

Every answer includes a **Caveat** section when:
- The answer depends on state/city law (e.g., *"Check your local tenant
  laws — state law may give you additional rights."*)
- Clauses are ambiguous or conflicting
- The answer is not a definitive yes/no
- The lease is silent on the issue

## Example Interactions

**Q:** *Can my landlord enter without notice?*

**A:** No — Section 6 requires your landlord to give at least 24 hours' written
notice before entering, except in emergencies (fire, flood, gas leak).

**Caveat:** Check your local tenant laws — some states require 24-48 hours'
notice and your local law may provide additional protections.

**Q:** *What happens if I break the lease early?*

**A:** You need to give 60 days' written notice and pay an early termination fee
equal to two months' rent. Alternatively, you can find a suitable replacement
tenant approved by the landlord, which reduces the fee to one month's rent.

**Caveat:** If you abandon the property without notice, the landlord may
accelerate rent and pursue legal remedies. Check your local laws — some states
require landlords to mitigate damages by finding a new tenant.
