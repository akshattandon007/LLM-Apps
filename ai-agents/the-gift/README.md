# The Gift

A heartfelt, shareable Next.js web app for gift-giving anxiety. Describe someone you love and get a personalized gift idea plus a poem or short story.

## Features
- Multi-step flow: Hero → Describe the person → Loading → Result
- Input fields for recipient details and shared memories
- Personalized gift ideas with explanations
- Heartfelt poems/stories featuring the recipient
- Retro and Cupcake themes
- Mobile-responsive design

## Technologies
- Next.js Pages Router
- TypeScript
- Tailwind CSS
- DaisyUI

## Getting Started
1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

4. Build for production:
```bash
npm run build
```
