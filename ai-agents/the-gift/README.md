# The Gift

**Personalized gift ideas that actually show you know them.**

---

## The Hook

> *I gave my dad a story about us fishing together and he cried.*

That's the whole thing right there.

---

## What This Is (And Why It Matters)

We've all been there. Standing in a store. Scrolling a website. Panic rising. The occasion is tomorrow and you have *nothing*.

So you buy a gift card. A candle. A generic something that says "I checked a box" instead of "I see you."

**Gift-giving anxiety is universal.** No one wants to be the gift card person. But finding something specific, meaningful, *right* — that takes time, attention, and the kind of knowing that comes from shared history.

The Gift doesn't replace your knowing. It *amplifies* it.

You tell us about them — their name, your relationship, what lights them up, a memory you share, what makes them laugh. We give you back:

- A **specific gift idea** (not "a fishing thing" — a custom leather-bound journal with the coordinates of your spot embossed on the cover)
- A **heartfelt poem or short story** featuring them
- An **explanation of why this gift is perfect** — so you can say it in your own words when they open it

---

## How It Works (Three Steps)

| Step | What Happens |
|------|--------------|
| **1. Tell us about them** | Name. Relationship. Interests. A shared memory. What makes them laugh. |
| **2. Wait a moment** | We're crafting something personal. (Takes about two seconds.) |
| **3. Get your gift** | A specific idea. A poem. The "why." Copy it. Share it. Or generate another. |

That's it. No accounts. No upsells. Just a tool that helps you be the gift-giver you already want to be.

## Example Gifts (Straight From the Code)

> **For the dad who fishes:**  
> *A custom leather-bound fishing journal with the coordinates of your favorite spot embossed on the cover. Comes with a handwritten-style note: "Every cast is a conversation, Dad. Here's to the next one."*

> **For the foodie friend:**  
> *A custom cookbook filled with recipes from your favorite shared meals, plus blank pages for future culinary adventures together.*

> **For the music-loving partner:**  
> *A vintage record player with a custom vinyl featuring recordings of songs that mark important moments in your relationship.*

> **For the traveler sibling:**  
> *A handmade travel journal with maps of places you've visited together, plus blank pages for future adventures.*

Each comes with a four-line poem and a heartfelt "why this is perfect" explanation.

---

## Features

- **Five persona-based gift sets** — fishing dad, gardening mom, foodie friend, music-loving partner, traveler sibling (with room to grow)
- **Every result includes three pieces** — specific gift idea, poem, and the "why it's perfect" rationale
- **Theme switcher** — Cupcake (soft, warm) or Retro (nostalgic, pixel-perfect)
- **Copy to clipboard** — One click, ready to paste into a note, card, or text
- **Generate Another** — Keep going until it feels exactly right
- **Zero friction** — No login, no tracking, no database. Runs entirely in your browser

## Tech Stack

| Layer | Choice |
|-------|--------|
| Framework | Next.js 14 (App Router) |
| Language | TypeScript |
| Styling | DaisyUI + Tailwind CSS |
| State | React `useState` (client-side only) |
| Deployment | Static export ready (`npm run build`) |

**No backend. No API keys. No database.** The "AI" is a curated set of mock gifts matched by simple keyword detection — proof that *thoughtfulness doesn't require a model, it requires intent.*

## Getting Started

```bash
# Clone the repo
git clone <your-repo-url>
cd the-gift

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and start describing someone you love.

**Build for production:**
```bash
npm run build
npm run start
```
