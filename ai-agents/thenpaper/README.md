# ThenPaper

**The day you were born, as a front page.**

ThenPaper pulls *real* history from Wikipedia's public **On This Day** feed —
what happened, who was born, who died, which holidays fell — for any date you
give it, then prints it as a charming ASCII newspaper front page. Give it your
birthday, an anniversary, a wedding day, or "today", and get the front page of
everything that ever happened on that date.

An optional LLM (Anthropic or OpenAI key) rewrites the headline, dek, and
"birthday twins" intro with real editorial flair. Without a key, polished
templates keep the paper printing — **zero runtime dependencies, zero API keys
required**.

$ python -m thenpaper 10/19

## Install

```bash
git clone https://github.com/akshattandon007/LLM-Apps
cd LLM-Apps/ai-agents/thenpaper

# No runtime pip installs needed — Python 3.10+ stdlib only.
python -m thenpaper --help
```

For tests:

```bash
pip install -r requirements.txt   # pytest only
python -m pytest tests/ -v
```

## Usage

```bash
# Any date
python -m thenpaper 12/25

# Today
python -m thenpaper today

# Full date (year focuses the front page on "your era")
python -m thenpaper 1990/10/19

# Toggle themes
python -m thenpaper 7/4 --theme evening
python -m thenpaper 7/4 --theme late

# Machine-readable output
python -m thenpaper 8/15 --json

# No network / no LLM
python -m thenpaper 6/1 --offline
python -m thenpaper 6/1 --no-llm
```

### Optional LLM voice

Set one key in your environment and the LLM writes the headline, dek, and
birthday-twins intro:

```bash
export ANTHROPIC_API_KEY=sk-ant-...        # or OPENAI_API_KEY=sk-...
python -m thenpaper 10/19
```

Any LLM failure (bad key, wrong model, no network) silently falls back to
templates — the paper always prints. Model names are overridable:

```bash
export THENPAPER_MODEL=claude-sonnet-4-5        # Anthropic default
export THENPAPER_OPENAI_MODEL=gpt-4o-mini       # OpenAI default
```

## Tests

```bash
python -m pytest tests/ -v
```

The suite is fully hermetic — the network and the LLM are mocked, so tests
pass offline with no keys.

- `tests/test_api.py` — date validation, On This Day parsing, URL padding,
  simulated fallback.
- `tests/test_paper.py` — ranking (recency + focus year), front-page assembly,
  ASCII rendering.
- `tests/test_voice.py` — template fallback, LLM success and failure paths.
- `tests/test_cli.py` — date parsing, JSON output, exit codes.

## Data source

[Wikipedia On This Day REST API](https://en.wikipedia.org/api/rest_v1/feed/onthisday)
— free, no auth, no rate limit for light personal use. Set a descriptive
`User-Agent` and be kind.
