# What's My Pet Thinking? 🐾

> **Finally, the inner monologue your pet has been hiding from you.**

---

## 🎯 What Is This?

You know that look. Your dog stares at a blank wall for 20 minutes like it's a season finale. Your cat methodically knocks every object off the coffee table — *tap, tap, CRASH* — and walks away satisfied. Your hamster runs a marathon on a wheel that goes exactly nowhere.

**You've wondered: "What is going on in that tiny, furry head?"**

This app answers that question. You describe the weird thing your pet is doing. We generate their **honest, dramatic, hilariously self-justifying inner monologue** — the one they'd never admit to your face.

No API keys. No cloud. No subscriptions. Just pure, offline, pet-obsessed chaos. 🌈

---

## 🤣 Why It's Hilarious (And Why You'll Send It to Everyone)

Because every pet owner has **400 photos of their pet doing something inexplicable** and *zero* insight into the reasoning. This app bridges that gap with the voice of someone who truly understands:

- **Dogs** who treat a cheese wrapper opening three houses down as a national security threat
- **Cats** conducting peer-reviewed gravity research at 3 AM
- **Hamsters** training for the Olympics in circular sprinting
- **Birds** arguing with their own reflection for 45 minutes
- **Rabbits** documenting their binky (that's a joy-twist, look it up) count

The monologues are specific, surreal, and *weirdly accurate*. You'll screenshot them. You'll post them. Your group chat will never be the same.

## 🛠 Tech Stack (For the Nerds)

| Layer | Choice | Why |
|-------|--------|-----|
| **Framework** | Next.js 14 (App Router) | Fast, modern, zero-config deploy |
| **Language** | TypeScript | Types = fewer "wait, what does this prop do?" moments |
| **Styling** | DaisyUI + Tailwind CSS | Cupcake theme 🧁, responsive, zero custom CSS hell |
| **State** | React `useState` | Simple. No Redux. No Context. Just works. |
| **Data** | **Mock generator** (keyword matching) | Works offline. No API costs. No rate limits. No "quota exceeded" sadness. |
| **Icons/Emoji** | Native Unicode | Lightweight, renders everywhere, looks great |

**No backend. No database. No external dependencies beyond the framework.** Clone → install → run → laugh.

## 🚀 Getting Started

```bash
# 1. Clone it (or just cd into the folder if you're already there)
cd whats-my-pet-thinking

# 2. Install deps
npm install

# 3. Fire it up
npm run dev

# 4. Open http://localhost:3000
# 5. Describe your pet. Laugh. Share. Repeat.
```

**Build for production:**
```bash
npm run build && npm start
```
