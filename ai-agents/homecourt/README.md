# 🏛️ HomeCourt — AI Judge for Daily Dilemmas

> *Anyone can settle a dinner argument, but only you can settle it with jurisprudence.*

**HomeCourt** is a playful AI arbitration tool. Two sides plead their case on a daily-life dilemma, pick a judge persona, and get a formal, quotable verdict with reasoning. Screenshot-ready and shareable.

## Personas

| Judge | Vibe |
|-------|------|
| 🧓 Grouchy Grandma | *"You kids and your nonsense. I've seen 70 winters."* |
| ⚖️ Reality-TV Judge | *"I've heard it all. Order in the court!"* |
| 🤖 Strict Logic AI | *"Only the facts matter. Emotion is irrelevant."* |
| 🧘 Zen Master | *"The path to peace is within. But first, dinner."* |
| 💁 Your Best Friend | *"Look, I love you both, but ONE of you is wrong."* |

## Usage

```bash
# Simulated demo
python main.py --simulate

# Interactive session (plead your case)
python main.py --plead
```

## Quick Start

```bash
pip install -r requirements.txt
python main.py --simulate
```

## Testing

```bash
pytest tests/ -v
```
